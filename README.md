# Matchpoint Frontend

Internal staffing tool — matches employees to projects by skills, level, and availability.

## Stack

- React 19 + TypeScript + Vite (SWC)
- TanStack Router + Query, zustand
- Tailwind CSS 4 + shadcn/ui (new-york), Radix, lucide
- API client generated by orval from the backend OpenAPI spec

## Development

```bash
pnpm install
pnpm dev          # Vite dev server on :5173, proxies /api to :8080
pnpm build        # tsc -b && vite build
pnpm lint
pnpm api:generate # regenerate API client (orval)
```
